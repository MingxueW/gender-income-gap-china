# Gender Income Differences in China

## Overview

This repository contains Stata code for my MSc Economics research project examining gender income differences among young workers in China.

## Data

The analysis uses China Family Panel Studies (CFPS) data from 2016, 2018, 2020, and 2022. The code constructs an unbalanced panel of individuals aged 25 or younger.

The underlying data are not included in this repository.

## Methods

The code covers data cleaning, variable construction, descriptive statistics, pooled OLS regressions, correlated random effects (Mundlak) models, robustness checks, and regression table and figure generation.

## Requirements

- Stata
- The relevant CFPS datasets and required Stata packages

The code relies on locally stored data files and may require adjustments to file paths before execution.

## Files

- `Full_latest_pipeline_CLEAN.do`: Stata analysis pipeline for the research project.
